帮我起一个 **唱片跑道音乐播放器 H5** 项目：

产品逻辑和交互要求参考同目录的 `PROJECT_PROMPT.md`，视觉严格参考 `KUGOU-design-guidelines.md` 和 `唱片跑道素材/music_player_UI_sample.jpg`。

必须使用现有本地素材：
- `唱片跑道素材/music_player_disk.png`：唱片外圈和跑道
- `唱片跑道素材/Runaway_Baby_Cover.jpeg`
- `唱片跑道素材/青春修炼手册_cover.PNG`
- `唱片跑道素材/star_crossing_night_cover.PNG`
- `songs/` 目录下三首 MP3 和对应 LRC 歌词

技术栈：
- Vite + React 18 + TypeScript
- 单页移动端 H5，不需要 React Router
- 状态使用 React Hooks，不引入 Zustand
- 样式使用 CSS Modules + CSS 变量
- 通用按钮图标使用 lucide-react

视觉：
- 移动端优先，主要视口 390 × 844，同时适配 375 × 812
- 严格遵守 `KUGOU-design-guidelines.md` 的色彩、字体、间距、圆角、阴影和动效
- 页面使用酷狗播放器的冰蓝渐变背景
- 唱片跑道是页面第一视觉中心，复用 `music_player_disk.png`，不要用 Canvas 重画唱片
- 三张专辑封面放在唱片透明中孔下方，切歌时同步更换
- 风格清新、年轻、轻盈，突出“有人和我一起听歌、一起跑”的陪伴感
- 不使用 emoji 作为按钮图标；毕业帽、爱心和星光彩蛋用 CSS/SVG 实现
- 不堆叠大量玻璃态卡片

核心播放器：
- 展示歌曲名、歌手、当前歌词、进度条、当前时间和总时长
- 支持上一首、播放/暂停、下一首，三首歌循环切换
- 真实播放 `songs/` 目录中的本地 MP3
- 解析对应 LRC，歌词随播放时间滚动并高亮
- 可以点击或拖动进度条跳转
- 播放时间以 `HTMLAudioElement.currentTime` 为唯一时间源
- 暂停时音频、歌词、进度、人物运动和歌曲彩蛋必须一起暂停

三首歌：
1. `runaway-baby.mp3`
   - 封面：`Runaway_Baby_Cover.jpeg`
   - 歌词：`runaway-baby.lrc`
   - 通用多人跑步场景
   - `00:29.25–00:37.95` 触发两位好友接力、递棒和短暂加速动画

2. `youth-training-manual.mp3`
   - 封面：`青春修炼手册_cover.PNG`
   - 歌词：`youth-training-manual.lrc`
   - 小人戴毕业帽，以散步或轻快踏步为主
   - 在 `00:03.33–00:12.17`、`01:22.07–01:30.03`、`02:39.49–02:47.58`、`03:29.20–03:37.58` 依次举左手、右手

3. `star-crossing-night.mp3`
   - 封面：`star_crossing_night_cover.PNG`
   - 歌词：`Star Crossing Night (feat. GALI).lrc`
   - 突出用户和一位好友，其他好友在外圈弱化显示
   - `01:21.95–01:28.45` 两人恰好相遇、停步抬头，头顶出现爱心和星光

唱片与小人：
- 唱片外圈可以缓慢自转，但人物公转是独立动画层，不能跟着唱片纹理一起旋转
- 默认 4 人，最多 8 人，包含用户本人
- 小人使用轻量 DOM/CSS/SVG 绘制，每个人有不同衣服颜色和名字
- 人物分布在 3 条相邻的同心椭圆跑道上
- 使用 `x = cx + rx * cos(θ)`、`y = cy + ry * sin(θ)` 计算轨迹
- 人物速度由歌曲 BPM 加稳定的个人 pace 系数决定，只用于制造自然相遇，不做速度排名
- 根据人物在椭圆上方或下方调整缩放和层级，形成自然前后关系
- 跑步动作要与移动速度同步，人物不能倒着跑、原地旋转或长期穿模
- 两人相遇时可以短暂击掌并显示粒子效果，同一对好友设置 12 秒冷却
- 开启陪跑时好友依次跑入；关闭、下线或被踢时减速挥手并跑出

陪跑交互：
- 提供明显的“开启/关闭陪跑”开关
- 点击非本人的小人，打开好友卡片
- 好友卡展示在线状态、关系标识、本周同听分钟、合跑圈数和击掌次数
- 可以将非本人的好友踢出跑道，需要二次确认
- 用户本人不能被踢

Demo 管理面板：
- 提供可折叠的“好友管理”底部面板
- 至少准备 8 个角色，支持模拟好友上线和下线
- 上线后播放入场动画，下线后播放退场动画
- 达到 8 人时禁止继续加入并提示跑道已满
- 提供“一键 2 人”“一键 4 人”“一键 8 人”三个快捷演示按钮

分享：
- 提供“生成陪跑周报”入口
- 生成可预览和下载的 9:16 PNG 分享卡
- 分享卡包含当前唱片画面、陪跑好友人数、本周同听分钟、合跑圈数、击掌次数、歌曲名、日期和文案“这一程，有人陪你跑”
- 当前人数和击掌次数需要与页面本次操作联动

交互要求：
- 所有按钮点击区域至少 44 × 44px
- 使用正式 Toast、底部抽屉和确认弹窗，不使用 `alert()`
- 弹窗支持遮罩关闭、关闭按钮和 Escape
- 适配 iPhone 安全区
- 支持 `prefers-reduced-motion`
- 页面不能出现横向滚动

部署要求：
- 项目必须能作为纯静态 H5 部署，不依赖后端、代理、远程音频或密钥
- 不修改原始素材；将 MP3 和 LRC 复制到 `public/assets/audio/`、`public/assets/lyrics/`
- 将 `Star Crossing Night (feat. GALI).lrc` 复制为公开文件 `star-crossing-night.lrc`
- 公开资源只使用英文小写和连字符文件名
- `vite.config.ts` 设置 `base: "./"`
- 运行时资源 URL 使用 `import.meta.env.BASE_URL` 构造，不使用本机绝对路径或硬编码域名
- 音频或歌词加载失败时显示非阻塞错误提示
- 最终部署目录为 `dist/`
